# BocaClean.com

Static, responsive website for Sobeida & Lizette Cleaning & Sanitizing Services.

## GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In Settings > Pages, deploy from the main branch root.
4. Add the custom domain `www.bocaclean.com` in GitHub Pages settings.
5. Configure the domain DNS records as GitHub instructs.

The site uses no framework or build step.
